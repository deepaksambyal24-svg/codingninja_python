
# COVID-19 Data Analysis Using Python

## Project Overview
This project analyzes COVID-19 data using Python and Pandas to
identify daily case surges and compare recovery rates between countries.

## Objectives
1. Identify peak daily new cases in Germany, France, and Italy.
2. Compare recovery rates between Canada and Australia
   as of December 31, 2020.
3. Clean and preprocess COVID-19 datasets.
4. Visualize analytical findings using Matplotlib.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel

## Key Skills
- Data cleaning and preprocessing
- Missing-value handling
- Data filtering and aggregation
- Date and time processing
- Daily case calculations
- Recovery-rate calculations
- Data visualization

## Project Files
- `problems.py` — Python analysis code
- `confirmed.xlsx` — Confirmed cases dataset, if included
- `deaths.xlsx` — Deaths dataset, if included
- `recovered.xlsx` — Recovered cases dataset, if included

## How to Run
1. Install Python.
2. Install the required libraries.
3. Place the input datasets in the appropriate location.
4. Run `problems.py`.

## Disclaimer
This project is for educational and analytical purposes.
A higher recovery rate alone does not establish better
overall pandemic management.
