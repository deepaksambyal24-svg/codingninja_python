## Skills covered

- **Python data stack:** Pandas, NumPy, Matplotlib and Seaborn
- **Data preparation:** data types, missing values, duplicates, reshaping and validation
- **Exploratory analysis:** descriptive summaries, grouping, filtering and correlation
- **Statistics:** sampling, probability, distributions, confidence intervals and hypothesis testing
- **Communication:** charts, labels, summaries and documented limitations

## Suggested learning sequence

1. Work through Pandas and NumPy exercises in `functions/lectures/` and `functions/problems/`.
2. Review statistics notes and scripts before interpreting analytical results.
3. Run the self-contained Vehicle Rental Pricing EDA project.
4. Revisit other learning scripts after obtaining their required datasets.
5. Build larger projects with a clear question, reproducible preparation, justified methods, evaluation, limitations and conclusions.

## Important distinction

This folder contains completed practice exercises and works in progress. A script appearing here does not imply that it is production-ready, independently tested, or backed by a complete dataset. Project READMEs should state prerequisites and limitations clearly.
